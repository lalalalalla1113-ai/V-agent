V-AGENT — как получить обычное приложение (.exe)

СБОРКА (один раз, на Windows)
1. Установите Python 3.12 с python.org (галочка "Add Python to PATH").
2. Распакуйте эту папку куда угодно.
3. Дважды щёлкните build.bat и подождите. Первый раз это несколько минут.
4. Готовый файл появится здесь: dist\V-AGENT.exe

Этот файл можно скидывать другим людям. Python им не нужен, запускается двойным щелчком.
Файл работает только на Windows. Для Mac нужна отдельная сборка на Mac.

СБОРКА ДЛЯ WINDOWS + MAC + ANDROID ЧЕРЕЗ GITHUB (бесплатно)
1. Зарегистрируйтесь на github.com и создайте новый репозиторий (Private).
2. Загрузите в него все файлы проекта (Add file -> Upload files).
   Папка .github должна загрузиться вместе с остальными.
3. Откройте вкладку Actions -> Build V-AGENT -> Run workflow.
4. Через 10-30 минут внизу страницы запуска появятся три файла (Artifacts):
   V-AGENT-windows (.exe), V-AGENT-mac (.zip), V-AGENT-android (.apk). Скачайте их.
Mac: файл собран без подписи Apple. Первый запуск: правый клик -> Открыть.
Если пишет "приложение повреждено": в Терминале  xattr -cr /путь/к/V-AGENT.app
Android: в настройках телефона разрешите установку из неизвестных источников.

КЛЮЧ ИИ
В приложении нет встроенных ключей. Каждый пользователь вставляет СВОЙ токен Cloudflare
(при первом запуске или потом в Настройках). Приложение работает по его токену.
Без токена всё открывается, но текст и картинки от ИИ не генерируются.

ЕСЛИ ИИ ПИШЕТ ПРО ОШИБКУ КЛЮЧА
Часто токен не может сам узнать Account ID. Впишите его вручную: Настройки -> Cloudflare ключ
-> поле Account ID. Он виден в адресной строке после входа на dash.cloudflare.com:
dash.cloudflare.com/<ВОТ_ЭТО_ID>/home  (можно вставить всю ссылку целиком).

ГДЕ ХРАНЯТСЯ ДАННЫЕ
Когда приложение запущено из .exe, все данные (профиль, чаты, картинки, напоминания)
лежат в папке  %APPDATA%\V-AGENT   (вставьте это в адресную строку Проводника).
Там же файл app.log: если что-то сломалось, пришлите его.
Ваши данные из старой папки ContentFarm в .exe не переносятся. У каждого, кто
запустит .exe, всё начнётся с чистого листа (экран знакомства).
Если хотите перенести свои данные: скопируйте содержимое ContentFarm в %APPDATA%\V-AGENT.

ЗАПУСК ИЗ ИСХОДНИКОВ (как раньше)
pip install -r requirements.txt
python main.py
В этом режиме данные лежат в папке ContentFarm рядом с проектом.

ЕСЛИ АНТИВИРУС РУГАЕТСЯ
Для файлов, собранных PyInstaller, это обычное ложное срабатывание.
Нажмите "Подробнее" -> "Выполнить в любом случае".
